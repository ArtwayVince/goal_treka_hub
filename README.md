# Goal Trekker Hub

Design and build a functional, mobile-first web application called JET OFF based on the specification in PROJECT JET OFF (pasted).md, merging the core functionality from https://github.com/ArtwayVince/J-off, https://github.com/ArtwayVince/Jetoff_Gro, and https://jet-off-goals-and-experiences--artwayltd.replit.app/.

Include:
1. From the Replit App (jet-off-goals-and-experiences--artwayltd.replit.app):
- The sliding hero/pilot banner showcasing featured destinations, milestones, and proposed pilot badges.
- Clean routing and views (/dashboard, /goals, /explore, /experiences/:id, /play, /readiness, /bookings, /provider, /provider/apply, /admin, /terms, /privacy, /safety).
- Authentication and user profiles with role switching.
- Clear legal microcopy and disclaimers ("Request for verified details only, not a booking", "Practice currency for missions, not real money").
- Provider application submission and moderation workflow.

2. From J-off (github.com/ArtwayVince/J-off):
- Interactive Yuby Resort Tour: walkthrough mode and interactive map, gate approach, reception security protocols, dress codes, verified facility pricing, and demonstrator notice.
- Curated experience marketplace across 4 categories (Experience & Enjoyment, Learn & Discover, Create & Build, Grow & Achieve) with verified provider listings.
- Long-term goal engine tracking self-reported savings (starting from ₦1,000) with encouraging, non-punitive coaching feedback.
- Virtual budget trade-off simulator starting with ₦100,000 in virtual game currency and real-life consequence feedback.
- JET OFF Readiness Coach with scenario-based checks.

3. From Jetoff_Gro (github.com/ArtwayVince/Jetoff_Gro):
- Gamified character growth: Mindset, Presence, Discipline, Network attributes, live XP bar, and level-up system.
- 10-Stage Path to Jet Off progression ladder.
- 3-step pilot mission chain: Mission 1 (The Aspiration), Mission 2 (Know Before You Go), Mission 3 (The Real Visit: Option A resort booking or Option B free alternative, photo upload, reflection, and guaranteed Level-Up).
- Daily challenges and streak tracking with milestone badges.
